# DBM Slint UI App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `dbm-app` Slint desktop binary — a 3-pane database manager (connection/schema sidebar, tabbed query editor + result view, status bar) with a per-connection accent border, FemtoVG rendering, and a tokio↔Slint async bridge to the `dbm-core` `Driver` trait.

**Architecture:** A single Rust binary crate (`app`, package `dbm-app`) that owns the Slint event loop. `.slint` markup defines the visual shell + a `global Theme` token singleton; Rust glue holds app state, converts `dbm-core` `ResultSet`/`Schema` into Slint `VecModel`s via pure (unit-tested) functions, and dispatches driver work onto a tokio multi-thread runtime, pushing results back with `slint::Weak::upgrade_in_event_loop`. The UI depends only on `dbm-core`'s `Driver` trait + frozen types and `dbm-connstore` for saved connections; concrete drivers are reached only through a boxed `AnyDriver` enum.

**Tech Stack:** Rust, Slint (FemtoVG renderer), tokio, dbm-core, dbm-connstore + driver crates

---

> **Frozen `dbm-core` contract this plan consumes** (do NOT redefine — import from `dbm-core`):
> `ResultSet { Tabular { cols, rows }, Documents(Vec<Json>), KeyValue(Vec<(String, RedisValue)>), Affected(u64) }`,
> `Column { name, type_name }`, `Row = Vec<Cell>`, `Cell { Null, Int, Float, Text, Bool, Bytes }` with `Cell::render() -> String`,
> `RedisValue { Str, Int, List, Nil }`, `Schema { databases }`, `Database { name, containers }`,
> `Container { name, kind, fields }`, `ContainerKind { Table, Collection, Keyspace }`, `Field { name, type_name, nullable }`,
> `Driver` (async: `connect`/`ping`/`schema`/`query`/`close`), `Query`, `ConnConfig`.
>
> **`dbm-connstore` contract this plan consumes:** `SavedConnection { id: String, name: String, engine: Engine, config: ConnConfig, color: String }`
> and a store with `list() -> Vec<SavedConnection>` and `load_password(id) -> Result<Option<String>>`. `Engine { Postgres, Mysql, Redis, Mongo }`.
> If the connstore plan finalized slightly different field names, adapt the field accessors in Task 5/6 only — the model-conversion fns and `.slint` stay the same.

> **Testing posture (per spec "app/UI is manual for MVP"):** Rust-side pure logic (model conversion, type mapping, accent parsing, `AnyDriver` dispatch) is TDD'd with the failing-test→impl→pass→commit loop. Pure `.slint` visual work uses: write `.slint` → `cargo build` (expect compile OK) → run app → **manual verification checklist** → commit. Manual checks are concrete and observable.

### Task 4: `AnyDriver` boxed-enum dispatch (Rust)

**Files:**
- Create: `app/src/dispatch.rs`
- Edit: `app/src/main.rs` (add `mod dispatch;`)

The `dbm-core::Driver` trait is **not object-safe** as-is: `connect` and `close` carry `where Self: Sized`, so `Box<dyn Driver>` cannot call them. We use a **boxed enum** `AnyDriver` that owns a concrete driver per `Engine` and forwards the async methods. This keeps the UI free of concrete-driver knowledge except at the single construction site, and sidesteps `Self: Sized` entirely.

```rust
//! Boxed-enum driver dispatch. The UI holds an `AnyDriver`, never a `dyn Driver`
//! (the `Driver` trait is not object-safe because `connect`/`close` are
//! `where Self: Sized`). Each variant owns a concrete driver and forwards the
//! async trait methods. Construction is the ONLY place the app names a concrete
//! driver crate.

use dbm_connstore::Engine;
use dbm_core::{ConnConfig, Driver, Query, ResultSet, Schema};
use dbm_core::error::{DbmError, Result};
use dbm_driver_postgres::PostgresDriver;

pub enum AnyDriver {
    Postgres(PostgresDriver),
    // Mysql(MysqlDriver), Redis(RedisDriver), Mongo(MongoDriver) — added when
    // those driver crates land; each new arm is a one-line forward below.
}

impl AnyDriver {
    /// Human label for an engine (used in the sidebar + palette).
    pub fn label(engine: Engine) -> &'static str {
        match engine {
            Engine::Postgres => "PostgreSQL",
            Engine::Mysql => "MySQL",
            Engine::Redis => "Redis",
            Engine::Mongo => "MongoDB",
        }
    }

    /// Whether this build can connect the engine (MVP wires Postgres only).
    pub fn is_supported(engine: Engine) -> bool {
        matches!(engine, Engine::Postgres)
    }

    /// Connect using the concrete driver for `engine`.
    pub async fn connect(engine: Engine, cfg: &ConnConfig) -> Result<Self> {
        match engine {
            Engine::Postgres => Ok(AnyDriver::Postgres(PostgresDriver::connect(cfg).await?)),
            other => Err(DbmError::Connection(format!(
                "{} not supported in this build yet",
                Self::label(other)
            ))),
        }
    }

    pub async fn ping(&self) -> Result<()> {
        match self {
            AnyDriver::Postgres(d) => d.ping().await,
        }
    }

    pub async fn schema(&self) -> Result<Schema> {
        match self {
            AnyDriver::Postgres(d) => d.schema().await,
        }
    }

    pub async fn query(&self, q: &Query) -> Result<ResultSet> {
        match self {
            AnyDriver::Postgres(d) => d.query(q).await,
        }
    }

    pub async fn close(self) -> Result<()> {
        match self {
            AnyDriver::Postgres(d) => d.close().await,
        }
    }
}
```

> Assumes `dbm_driver_postgres::PostgresDriver` exists and implements `dbm_core::Driver` (from the postgres-driver plan). If that type name differs, change only the `use` + the variant body. Verify the `Engine` enum variants match the connstore plan on first build.

```rust
//! Pure conversion from dbm-core result/schema types into flat view-model
//! structs the UI binds to. No Slint imports here so it stays unit-testable;
//! `main.rs` maps these into the Slint-generated structs.

use dbm_core::result::{Cell, RedisValue, ResultSet};
use dbm_core::schema::{ContainerKind, Schema};

#[derive(Debug, Default, Clone)]
pub struct VmCell {
    pub text: String,
    pub is_null: bool,
}

#[derive(Debug, Default, Clone)]
pub struct VmColumn {
    pub name: String,
    pub type_name: String,
}

/// Flat grid model covering all four ResultSet variants.
#[derive(Debug, Default, Clone)]
pub struct GridModel {
    pub columns: Vec<VmColumn>,
    pub rows: Vec<Vec<VmCell>>,
    /// Pretty JSON for Documents.
    pub json: String,
    pub is_documents: bool,
    /// Status text for Affected (e.g. "3 rows affected").
    pub status: String,
}

#[derive(Debug, Default, Clone)]
pub struct VmTreeNode {
    pub label: String,
    pub depth: i32,
    pub kind: String,
}

fn redis_cell(v: &RedisValue) -> VmCell {
    match v {
        RedisValue::Str(s) => VmCell { text: s.clone(), is_null: false },
        RedisValue::Int(i) => VmCell { text: i.to_string(), is_null: false },
        RedisValue::List(items) => VmCell { text: items.join(", "), is_null: false },
        RedisValue::Nil => VmCell { text: "(nil)".into(), is_null: true },
    }
}

/// Convert any ResultSet into the grid view-model.
pub fn to_grid_model(rs: &ResultSet) -> GridModel {
    match rs {
        ResultSet::Tabular { cols, rows } => GridModel {
            columns: cols
                .iter()
                .map(|c| VmColumn { name: c.name.clone(), type_name: c.type_name.clone() })
                .collect(),
            rows: rows
                .iter()
                .map(|row| {
                    row.iter()
                        .map(|cell| VmCell {
                            text: cell.render(),
                            is_null: matches!(cell, Cell::Null),
                        })
                        .collect()
                })
                .collect(),
            ..Default::default()
        },
        ResultSet::KeyValue(pairs) => GridModel {
            columns: vec![
                VmColumn { name: "key".into(), type_name: "".into() },
                VmColumn { name: "value".into(), type_name: "".into() },
            ],
            rows: pairs
                .iter()
                .map(|(k, v)| vec![VmCell { text: k.clone(), is_null: false }, redis_cell(v)])
                .collect(),
            ..Default::default()
        },
        ResultSet::Documents(docs) => {
            let json = serde_json::to_string_pretty(docs).unwrap_or_else(|_| "[]".into());
            GridModel { json, is_documents: true, ..Default::default() }
        }
        ResultSet::Affected(n) => GridModel {
            status: format!("{} rows affected", n),
            ..Default::default()
        },
    }
}

/// Flatten a Schema into depth-tagged tree nodes for the sidebar.
pub fn to_tree_model(schema: &Schema) -> Vec<VmTreeNode> {
    let mut out = Vec::new();
    for db in &schema.databases {
        out.push(VmTreeNode { label: db.name.clone(), depth: 0, kind: "database".into() });
        for c in &db.containers {
            let kind = match c.kind {
                ContainerKind::Table => "table",
                ContainerKind::Collection => "collection",
                ContainerKind::Keyspace => "keyspace",
            };
            out.push(VmTreeNode { label: c.name.clone(), depth: 1, kind: kind.into() });
            for f in &c.fields {
                out.push(VmTreeNode {
```

```rust
//! Accent color helpers: connstore stores the per-connection color as a hex
//! string; the UI needs a `slint::Color`.

use slint::Color;

/// Parse "#rrggbb" or "rrggbb" into a Slint Color. Returns None on bad input
/// so the caller can fall back to the default accent.
pub fn parse_hex(s: &str) -> Option<Color> {
    let h = s.strip_prefix('#').unwrap_or(s);
    if h.len() != 6 {
        return None;
    }
    let r = u8::from_str_radix(&h[0..2], 16).ok()?;
    let g = u8::from_str_radix(&h[2..4], 16).ok()?;
    let b = u8::from_str_radix(&h[4..6], 16).ok()?;
    Some(Color::from_rgb_u8(r, g, b))
}

/// Parse with a fallback to the spec's default accent (#3b82f6).
pub fn accent_or_default(s: &str) -> Color {
    parse_hex(s).unwrap_or_else(|| Color::from_rgb_u8(0x3b, 0x82, 0xf6))
}
```

```rust
slint::include_modules!();

mod dispatch;
mod model;
mod theme;

use std::rc::Rc;
use std::sync::Arc;

use dbm_connstore::{Engine, SavedConnection};
use slint::{Model, ModelRc, VecModel, SharedString};

use dispatch::AnyDriver;

fn engine_label(e: Engine) -> &'static str {
    AnyDriver::label(e)
}

fn main() -> Result<(), slint::PlatformError> {
    // tokio multi-thread runtime on a background thread; the Slint event loop
    // owns the main thread. Async results return via upgrade_in_event_loop.
    let rt = tokio::runtime::Builder::new_multi_thread()
        .enable_all()
        .build()
        .expect("tokio runtime");
    let rt = Arc::new(rt);

    let window = MainWindow::new()?;

    // Load saved connections from connstore (sync list; passwords loaded lazily).
    let saved: Vec<SavedConnection> = dbm_connstore::open_default()
        .and_then(|store| store.list())
        .unwrap_or_default();

    // Build the ConnItem model for the sidebar.
    let conn_items: Vec<ConnItem> = saved
        .iter()
        .map(|s| ConnItem {
            id: s.id.clone().into(),
            name: s.name.clone().into(),
            engine: engine_label(s.engine).into(),
            color: theme::accent_or_default(&s.color),
            supported: AnyDriver::is_supported(s.engine),
        })
        .collect();
    let conn_model: Rc<VecModel<ConnItem>> = Rc::new(VecModel::from(conn_items));
    window.set_connections(ModelRc::from(conn_model.clone()));
    window.set_schema_tree(ModelRc::from(Rc::new(VecModel::<TreeNode>::default())));

    // Connect callback: spawn driver work on tokio, push schema back to UI.
    {
        let weak = window.as_weak();
        let rt = rt.clone();
        let saved = saved.clone();
        window.on_connect_clicked(move |idx| {
            let i = idx as usize;
            let Some(sc) = saved.get(i).cloned() else { return; };
            // Reflect selection + accent immediately.
            if let Some(w) = weak.upgrade() {
                w.set_selected_conn(idx);
                w.global::<Theme>().set_accent(theme::accent_or_default(&sc.color));
                w.set_status_conn(SharedString::from(sc.name.clone()));
            }
            let weak2 = weak.clone();
            let rt2 = rt.clone();
            rt.spawn(async move {
                // Inject password from keychain, then connect + fetch schema.
                let mut cfg = sc.config.clone();
                if cfg.password.is_none() {
                    if let Ok(store) = dbm_connstore::open_default() {
                        if let Ok(Some(pw)) = store.load_password(&sc.id) {
                            cfg.password = Some(pw);
                        }
                    }
                }
                let result = async {
                    let driver = AnyDriver::connect(sc.engine, &cfg).await?;
                    let schema = driver.schema().await?;
                    Ok::<_, dbm_core::error::DbmError>(schema)
                }
                .await;

                let _ = slint::invoke_from_event_loop(move || {
                    if let Some(w) = weak2.upgrade() {
                        match result {
                            Ok(schema) => {
                                let nodes = model::to_tree_model(&schema);
                                let rows: Vec<TreeNode> = nodes
                                    .into_iter()
                                    .map(|n| TreeNode {
                                        label: n.label.into(),
                                        depth: n.depth,
                                        kind: n.kind.into(),
                                    })
                                    .collect();
                                w.set_schema_tree(ModelRc::from(Rc::new(VecModel::from(rows))));
                                w.set_status_latency(SharedString::from("connected"));
                            }
                            Err(e) => {
                                w.set_status_latency(SharedString::from(format!("error: {e}")));
                            }
                        }
                    }
                });
                let _ = rt2; // keep runtime alive for this task
            });
        });
    }

    window.run()
}
```

> `dbm_connstore::open_default()`, `store.list()`, and `store.load_password(&id)` are the assumed connstore API. If the finalized connstore plan named them differently, adjust only these calls. `invoke_from_event_loop` + `Weak::upgrade` is the canonical 1.x cross-thread push pattern — verify the exact `slint::invoke_from_event_loop` path on first build.

Add handlers before `window.run()`:

```rust
    // new tab
    {
        let weak = window.as_weak();
        let tab_texts = tab_texts.clone();
        window.on_new_tab(move || {
            let Some(w) = weak.upgrade() else { return; };
            // save current text into active slot
            let active = w.get_active_tab() as usize;
            {
                let mut t = tab_texts.borrow_mut();
                if let Some(slot) = t.get_mut(active) { *slot = w.get_query_text().to_string(); }
                t.push(String::new());
            }
            let count = tab_texts.borrow().len();
            set_tab_titles(&w, count);
            w.set_active_tab((count - 1) as i32);
            w.set_query_text(SharedString::default());
        });
    }
    // close tab
    {
        let weak = window.as_weak();
        let tab_texts = tab_texts.clone();
        window.on_close_tab(move || {
            let Some(w) = weak.upgrade() else { return; };
            let mut t = tab_texts.borrow_mut();
            if t.len() <= 1 { return; }
            let active = w.get_active_tab() as usize;
            t.remove(active.min(t.len() - 1));
            let new_active = active.saturating_sub(1).min(t.len() - 1);
            let text = t[new_active].clone();
            let count = t.len();
            drop(t);
            set_tab_titles(&w, count);
            w.set_active_tab(new_active as i32);
            w.set_query_text(SharedString::from(text));
        });
    }
    // select tab
    {
        let weak = window.as_weak();
        let tab_texts = tab_texts.clone();
        window.on_select_tab(move |idx| {
            let Some(w) = weak.upgrade() else { return; };
            let i = idx as usize;
            let mut t = tab_texts.borrow_mut();
            if i >= t.len() { return; }
            // save current, load target
            let active = w.get_active_tab() as usize;
            if let Some(slot) = t.get_mut(active) { *slot = w.get_query_text().to_string(); }
            let text = t[i].clone();
            drop(t);
            w.set_active_tab(idx);
            w.set_query_text(SharedString::from(text));
        });
    }
    // row nav (j/k)
    {
        let weak = window.as_weak();
        window.on_move_row(move |delta| {
            if let Some(w) = weak.upgrade() {
                let n = w.get_grid_col_count();
                let total = if n > 0 { (w.get_grid_cells().row_count() as i32) / n } else { 0 };
                if total > 0 {
                    let next = (w.get_selected_row() + delta).clamp(0, total - 1);
                    w.set_selected_row(next);
                }
            }
        });
    }
    // palette open/close + filter + choose
    {
        let weak = window.as_weak();
        let saved = saved.clone();
        window.on_toggle_palette(move || {
            if let Some(w) = weak.upgrade() {
                let opening = !w.get_palette_open();
                w.set_palette_open(opening);
                if opening {
                    // seed with all connections + current schema tables
                    let mut items: Vec<PaletteItem> = saved.iter().map(|s| PaletteItem {
                        label: s.name.clone().into(), kind: "connection".into(),
                    }).collect();
                    for n in w.get_schema_tree().iter().filter(|n| n.kind == "table") {
                        items.push(PaletteItem { label: n.label.clone(), kind: "table".into() });
                    }
                    w.set_palette_items(ModelRc::from(Rc::new(VecModel::from(items))));
                }
            }
        });
    }
    {
        let weak = window.as_weak();
        let saved = saved.clone();
        window.on_palette_filter(move |q| {
            if let Some(w) = weak.upgrade() {
                let needle = q.to_lowercase();
                let mut items: Vec<PaletteItem> = saved.iter()
                    .filter(|s| s.name.to_lowercase().contains(&needle))
                    .map(|s| PaletteItem { label: s.name.clone().into(), kind: "connection".into() })
                    .collect();
                for n in w.get_schema_tree().iter()
                    .filter(|n| n.kind == "table" && n.label.to_lowercase().contains(&needle)) {
                    items.push(PaletteItem { label: n.label.clone(), kind: "table".into() });
                }
                w.set_palette_items(ModelRc::from(Rc::new(VecModel::from(items))));
            }
        });
    }
    {
        let weak = window.as_weak();
        window.on_palette_choose(move |_idx| {
            // MVP: choosing closes the palette. Jump-to wiring is post-MVP.
            if let Some(w) = weak.upgrade() { w.set_palette_open(false); }
        });
    }
```

> `w.get_schema_tree().iter()` requires `use slint::Model;` (already imported in Task 6). `saved` is `Vec<SavedConnection>` cloned per closure; if clippy flags clone count, wrap in `Rc` once — fine for MVP.
